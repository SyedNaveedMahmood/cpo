# Paper 1 experiment matrix

## Required

1. Tier 1 controlled benchmark: direct CPO/HCH on Qwen2.5-3B, Qwen2.5-7B, Mistral-7B-v0.3.
2. Tier 2A LLMBar-Adversarial CPO-mined subset.
3. Tier 2B WildBench CPO-mined subset when enough response-pair data is exposed.
4. Direct, locked, conflict-audit, decomposed, and context-forward judging methods.
5. Metrics: OSR, POR-C, POR-NC, HHR, RSR, PSR, family breakdown.
6. Confidence intervals by bootstrap.

## Optional

1. Llama-3.1-8B-Instruct if Hugging Face access is granted.
2. Human annotation over 100-200 Tier 2 pairs.
3. Additional Gemma/Llama-family model if hardware permits.
